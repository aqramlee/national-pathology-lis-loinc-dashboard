# National Pathology LIS-LOINC Mapping Catalogue — dashboard

Live dashboard: https://aqramlee.github.io/national-pathology-lis-loinc-dashboard/

Interactive view of catalogue v1.0: a D3.js network of how orderable pathology tests group into panels, LOINC mapping coverage by discipline and workload subcategory, and a searchable test register.

`index.html` is self-contained (data embedded; D3.js loaded from cdnjs). The source CSV/XLSX files are kept in a separate private repository.
